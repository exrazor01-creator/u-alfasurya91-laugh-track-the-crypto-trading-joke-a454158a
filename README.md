# Laugh Track: The Crypto Trading Joke Contest

**Entry:** "Our trading group chat has two messages: “buy the dip” and “why is it still dipping” — posted by the same person, three minutes apart."

**Characters:** 134 (gate: 1–200, one line)

## Why it fits the brief

1. **On subject:** a one-line joke about crypto and trading life, with a clear setup (the group chat) and a turn.
2. **Real laugh:** the payoff rewards the setup — both messages come from the same person, three minutes apart.
3. **True to trading life:** the group chat is the recognisable detail; the dip-buyer and the panicker are one and the same trader, exactly how group chats read in a downtrend.
4. **Tight:** no throat clearing, no wasted slang; the punchline lands on the last words.
5. **Repeatable:** short enough to tell a friend verbatim, and it holds up on a second read.

`main.py` writes the line to `/output/entry.txt` and prints it.
